# Storybook documentation

Build *The Shape Between* with the [quick start](quickstart.md). The
full-page storybook and the descriptive manuscript have separate build flows.

- [Architecture](architecture.md) describes the story schema and render code.
- [Rendering pipeline](rendering_pipeline.md) explains the book producers and
  artifact checks.
- [Descriptive manuscript](manuscript/README.md) links to the published HTML
  and PDF and gives the pinned render instructions.
- [Forking guide](forking_guide.md) describes how to adapt the story and
  publication metadata.
- [Output conventions](output_conventions.md) identifies generated files
  and the published snapshots.
- [Testing philosophy](testing_philosophy.md), [style guide](style_guide.md),
  [troubleshooting](troubleshooting.md), and [agent instructions](agent_instructions.md)
  cover maintenance.
